# ❤️ Love For Fayrouz

A beautiful interactive romantic website created with ❤️ by **Al-Ameen Umar (ANSIT)**.

## ✨ Features

- ❤️ Animated loading screen
- 🎵 Background music
- 🌌 Animated stars
- 💖 Floating hearts
- ✨ Sparkle effects
- 💌 Love letter with typewriter effect
- 📸 Beautiful photo gallery
- 🔍 Full-screen image lightbox
- 🎁 Surprise section
- 😂 Funny "Do you love me?" game
- 🏃 Escaping "NO" button
- ❤️ Growing "YES" button
- 📱 Mobile responsive
- 🌍 GitHub Pages ready
